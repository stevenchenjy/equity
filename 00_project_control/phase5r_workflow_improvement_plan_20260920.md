# 四项投资工作流标准：实施计划与验收

授权：2026-09-20 用户要求提出改进计划并执行。目标为五年长期持有、可论证的成倍增长潜力、按市场变化调整研究策略，以及稳定的数据和新闻收集。投资结果本身需要未来表现验证；本轮交付是可执行的机制与可审计的当前研究结果。

1. **长期决策纪律**：技术分下降独立触发研究复核而非全仓退出；明确的来源支持的 thesis 失效才生成退出研究方案，硬集中度风险仍可及时复核。重大披露方向未知时中性计分。按标的保存不同有效收盘确认，价格正常变化不重置相同研究方案。缺 thesis/估值显示待补齐，不能包装为长期论证已通过。
2. **长期增长研究**：扩大 SEC 研究覆盖，候选队列纳入基本面排序且不依赖每日成交活跃度。对每只持仓维护公司特定问题、反证指标、来源与观察日期；计算明确假设下的 3/5 年每股价值、稀释敏感性及 2×/3× 必要条件。来源事实、条件假设和未知项分开，情景不会自动成为生产价格目标。
3. **有边界的市场响应**：以同一有效收盘的基准回撤和全池广度识别正常/谨慎/压力状态。连续两个压力收盘才把新增资金复核从两日延长到三日；连续三个正常收盘恢复。阈值为明确研究规则，不是优化收益的参数。不改变已批准的 50% 主动股票上限、15% 单股上限、500 美元储备及核心目标，不以该状态触发退出。
4. **数据、新闻与健康分层**：修复有确证的 XBRL 标签和期间处理；未知债务不补零。纳入 IOT/RBRK/NVDA 官方 IR/新闻 RSS，独立于晨间 EOD 刷新检查 08:15、11:15、16:45、20:15 ET。限制超时、请求次数、来源域名和内容大小；去重、时间检验、失败保留与陈旧标记。运行成功、财务完整、研究完整和新闻覆盖分别报告。
5. **验证与上线**：新增真实业务场景回归，全套原有测试，离线重建当前生产副本，有限公共新闻源验证，静态无发送/无交易边界检查。保留已有研究证据后使用既有 GitHub→runtime 路径部署并核对结果。公开研究刷新不调用发送器。记录版本、修复前后覆盖、未解决来源缺口和长期验证要求。

验收记录写入 `08_reviews/phase5r_workflow_implementation_20260920.md`。后续 30–60 个交易日可用于观察工程成功率、延迟、字段覆盖及事件遗漏；不能用这段短历史声称五年收益达标或调优投资参数。

生产模型调用保持关闭。所有仓位输出均为研究复核，真实操作仍由用户独立决定。将所有者审批变成每日研究的必经步骤并不在本计划内。
